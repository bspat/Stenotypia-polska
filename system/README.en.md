## Plugin
In order to use PSS inside of the [Plover software](https://opensteno.org/plover/) one needs plover-polish-pss plugin.

Supported machine types:
* keyboard
* Gemini PR

### Installation

#### Automatic

PSS Plugin is available inside Plover Plugin Manager. In order to install it, find it on the list and clisk "Install" button.

#### Manual

1. Download the plover-polish-pss directory
2. Paste it into dictionary containing Plover
3. Run Terminal with admin privileges
4. Run the following command: `.\plover_console.exe -s plover_plugins install .\plover-polish-pss`

### Usage

In order to begin using the plugin, choose "Configure" and pick PSS in System tab. Then, follow according to standard Plover usage practices.
