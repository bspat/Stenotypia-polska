## Plugin
Plugin plover-polish-pss pozwala na korzystanie z [programu Plover](https://opensteno.org/plover/) z użyciem PSS.

Obsługuje następujące protokoły:
- klawiatura
- Gemini PR

### Instalacja

#### Automatyczna

Plugin jest dostępny z poziomu Managera Pluginów wewnątrz programu Plover. Aby go zainstalować, należy go odszukać na liście i wybrać opcję "Instaluj".

#### Ręczna

1. Należy pobrać cały katalog plover-polish-pss
2. Należy wkleić go do katalogu zawierającego program Plover
3. Uruchomić w tym miejscu linię komend z uprawnieniami administratora
4. W linii komend podać następujące polecenie: `.\plover_console.exe -s plover_plugins install .\plover-polish-pss`

### Użytkowanie

Aby zacząć korzystać z pluginu, należy wejść w opcję "Konfiguruj", a następnie w zakładce System wybrać PSS. Dalej należy postępować zgodnie ze standardowymi zaleceniami twórców oprogramowaia.

### Uwaga

Instalację przeprowadza się na własną odpowiedzialność - pomimo podjęcia najlepszych starań, aby plugin nie zawierał błędów,
autor nie gwarantuje poprawności i nie bierze odpowiedzialności za korzystanie z pluginu.
