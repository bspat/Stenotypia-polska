# Polish Machine Stenography

[![pl](https://img.shields.io/badge/lang-pl-green)](https://github.com/bspat/Stenotypia-polska/blob/main/README.md)

This repository is dedicated to Polish Steno Theory (pl. Polski System Stenotypii - PSS) - steno theory made with polish language in mind. Here, one can also find the polish translation of coursebook "West Slavic Machnie Stenography" by Priscilla Trillo.

Questions, notes and requests please mail to: polskisystemstenotypii@gmail.com

## What is a machine stenography
Machine stenography - referred also as steno - is the art of quick typing using special keyboards. Users can reach speed up to 300 words per minute. It benefits from using a chords (i.e. the act of pressing a few keys at the same time), which allows to surpass limits of traditional keyboards (one action, one character). Even though it's widely used in the West (e.g. at the court), it remains nearly unknown in Poland.

## What is Polish Steno Theory (PSS)
Polish Steno Theory - pl. Polski System Stenotypii, abbreviated to PSS - is a steno theory made specifically for polish language, to some extend based on theory of Priscilla Trillo from 2023.

Features of PSS:
* regular rules
* clearly stated way of resolving conflicts between chords
* usage-oriented treatment of language (unlike english theories, which are phonetically-oriented)
